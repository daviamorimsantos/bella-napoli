# Bella Napoli - Projeto demonstrativo

Site de uma pizzaria fictícia criado para portfólio.

## Publicação na Vercel
1. Crie um repositório no GitHub.
2. Envie `index.html` e `style.css`.
3. Na Vercel, importe o repositório.
4. Framework: Other / nenhum framework.
5. Build command: deixe vazio.
6. Output directory: deixe vazio.
7. Deploy.

## Personalização
Troque:
- nome da pizzaria;
- telefone do WhatsApp (`5517999999999`);
- preços;
- textos;
- fotos;
- endereço e horários.

As fotos deste modelo usam imagens externas do Unsplash.
